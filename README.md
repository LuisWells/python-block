# Python | Block

Repositorio de aprendizaje de Python desde cero hasta nivel avanzado, con ejercicios, prácticas y proyectos enfocados en automatización, análisis de datos, testing y desarrollo profesional.

## Objetivos

- Dominar los fundamentos de Python.
- Resolver problemas mediante código claro y mantenible.
- Automatizar tareas con archivos TXT, CSV, Excel y JSON.
- Trabajar con bases de datos, APIs y análisis de datos.
- Aplicar pruebas automatizadas y buenas prácticas.
- Construir proyectos que formen un portafolio profesional.

## Ruta de aprendizaje

1. Fundamentos
2. Control de flujo
3. Estructuras y funciones
4. Archivos y automatización
5. Programación orientada a objetos
6. Datos y APIs
7. Testing y calidad
8. Python avanzado
9. Proyectos integradores

## Metodología

Cada módulo incluirá teoría breve, ejemplos, práctica guiada, retos individuales y evidencias de aprendizaje. El progreso detallado se registrará en Notion y el código se versionará en este repositorio.
